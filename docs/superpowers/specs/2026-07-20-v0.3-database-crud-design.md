# v0.3 Database CRUD Design

## Scope

v0.3 upgrades the generator from a Spring Boot skeleton to a more useful project starter. The release fixes controller route pluralization, preserves PascalCase entity names, generates real MyBatis-Plus CRUD when MySQL/MyBatis-Plus are enabled, keeps lean in-memory CRUD when those features are disabled, and updates docs/tests to match the new behavior.

## Architecture

The generator keeps the existing single-file rendering style for this release to avoid a broad refactor. `render_service_impl` becomes feature-aware and dispatches to either a MyBatis-Plus renderer or the existing in-memory renderer. Controller path generation uses the already-plural table name as the source of truth and converts underscores to hyphens without pluralizing again.

## Data Flow

For database-enabled generated projects, controllers call service interfaces, service implementations map DTOs to entities, mapper methods persist entities, and VO conversion still happens inside the service. Pagination uses MyBatis-Plus `Page` and `QueryWrapper`, with keyword search across up to three string fields. Generated tests use H2 in MySQL mode so `mvn test` can verify Spring context without a live MySQL service.

For lean generated projects, controllers and service interfaces stay identical, while service implementations continue using `ConcurrentHashMap`. This keeps generated lean projects runnable without MyBatis-Plus, MySQL, or datasource configuration.

## Error Handling

Database-backed `getById`, `update`, and `delete` throw `NotFoundException` when a row is missing. Lean mode keeps the existing behavior. Validation annotations remain generated from field metadata.

## Testing

Tests cover route path generation, database-backed service implementation contents, lean mode preservation, Mockito-free generated test dependencies, documentation updates, and version bump metadata. CLI smoke generation and Maven package remain part of verification.
